# Confidence-Aware Subtomogram Curation under a Missing Wedge

Classify 32³ cryo-electron tomography (cryo-ET) subtomograms into 10 macromolecular
classes and output a confidence score for every prediction. The task is deliberately
hard: −20 dB coloured noise, a missing-wedge point-spread function, molecular crowding,
conformational variants, and a train→test acquisition shift (thicker ice, higher
defocus, narrower tilt range).

The final solution is a compact, CPU-friendly pipeline built from **invariant feature
engineering + small neural networks**, rather than a large 3D CNN.

## Results

Validation is grouped by tomogram (`GroupKFold`, 3 folds) so no tomogram appears in both
training and validation. A second pseudo-CD holdout simulates the test-domain shift.

| Stage | Features | Model | OOF total |
|---|---|---:|---:|
| M2 baseline | 29 | logistic regression | 0.394 |
| + conformer specialists | 29 | logreg + binary heads | 0.414 |
| MLP ensemble | 29 | 3-seed MLP | 0.4193 |
| Feature bank | 74 | logistic regression | 0.4701 |
| **Final** | **74** | **3-seed MLP + specialists** | **0.4773** |

Final OOF breakdown: **macro F1 0.474 · conformer accuracy 0.327 · min-class F1 0.244 ·
selective accuracy 0.666**. Pseudo-CD score: **0.4837**.

The competition score is a weighted combination of macro F1 (30%), conformer accuracy
(20%), min-class F1 (15%), and selective accuracy (35%). Only the *ranking* of
confidences matters for the selective term.

## Approach

1. **Per-volume normalisation** — clip the 1st–99th percentile and z-score each tomogram.
   This removes per-tomogram gain and offset, which span roughly ×3.4.
2. **74 invariant features** per volume:
   - 14 log radial Fourier-power bins,
   - 15 spatial/shape cues (moments, tail fractions, shell masses, self-correlations),
   - 30 spherical-harmonic shell-power features (`l = 0…4`, 6 radial shells),
   - 12 within-shell standard deviation / skew features,
   - 3 inertia-tensor eigenvalue ratios.
3. **3-seed MLP ensemble** (`74 → 64 → 10`) with class-weighted cross-entropy.
4. **Conformer specialists** — one binary MLP per open/closed pair
   (`chaperonin`, `atpase`), trained only on that pair's rows. A specialist may override
   the 10-way label only when the 10-way head already predicts inside the pair, which
   preserves per-class coverage.
5. **Confidence calibration** — ensemble maximum probability multiplied by fixed,
   bounded per-class constants, plus a tiny row-order tie-break.
6. **Safety gates** — if a class disappears or one class exceeds 50% of predictions,
   fall back to the unmodified 10-way head.

Inference takes roughly 74 s on CPU with the released data.

## Quickstart

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# Put the released dataset files in ./data (see data/README.md)
python solution.py data submissions/submission.csv
```

`solution.py` also works with explicit paths:

```bash
python solution.py /path/to/public_dir /path/to/submission.csv
```

The output has exactly three columns — `particle_id, label, confidence` — one row per
test particle in `test.csv` order.

## Data

The dataset is **not included** in this repository because the volume arrays are large
(`train_volumes.npy` is 179 MB) and the competition data is not redistributed here.
See [`data/README.md`](data/README.md) for the expected files, shapes, and layout.

## Research archive

`research/` contains the scripts used during development: baselines, diagnostics,
augmentation studies, TTA/ranking experiments, the failed 3D-CNN attempts, and the
final feature-bank work. These scripts are preserved for transparency and are not a
packaged library. They expect the dataset at `../data` and regenerate intermediate
caches locally.

The polished technical write-up is in [`docs/SOLUTION_GUIDE.md`](docs/SOLUTION_GUIDE.md).

## Reproducibility notes

- Developed with Python 3.12 and PyTorch 2.6 on CPU. `scipy>=1.15` is required for
  `scipy.special.sph_harm_y`.
- Seeds are fixed, but exact predictions can drift slightly across PyTorch versions or
  hardware backends.
- The committed `submissions/submission.csv` was generated by the validated final
  pipeline (74 features, 3-seed ensemble, specialists).
